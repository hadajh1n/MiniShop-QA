# Checklist

## 1. Регистрация

- Успешная регистрация
- Валидация email
- Валидация пароля
- Валидация подтверждающего пароля
- Регистрация с уже существующем email

## 2. Авторизация

- Успешная авторизация
- Неуспешная авторизация
- Валидация обязательных полей

## 3. Товары

- Получение списка товаров авторизованным пользователем
- Получение товаров без авторизации
- Валидация данных товара

## 4. Заказы

- Создание заказа авторизованным пользователем
- Создание заказа неавторизованным пользователем
- Валидация данных заказа
- Валидация stock

## 5. Статусы заказа

- Корректные переходы между статусами
- Некорректные переходы между статусами
- Отмена заказа
