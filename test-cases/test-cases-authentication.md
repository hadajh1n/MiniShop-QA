# Test Cases Authentication

## TC-AUTH-001 - Успешная аутентификация

**Description:** Проверка аутентификации пользователя с зарегистрированными в системе данными

**Preconditions:**
- Пользователь зарегистрирован
- Открыт экран аутентификации

**Test Data:**
- Email: 'test123@gmail.com'
- Password: 'Test12345!'

**Steps:**
1. Ввести зарегистрированный в системе email в поле Email
2. Ввести зарегистрированный в системе пароль в поле Password
3. Нажать на кнопку авторизации

**Expected Result:**
- Аутентификация выполнена успешно
