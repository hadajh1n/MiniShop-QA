# Test Cases Registration

## TC-REG-001 - Успешная регистрация

**Description:** Проверка регистрации пользователя с валидными данными

**Preconditions:**
- Пользователь не зарегистрирован
- Открыт экран регистрации

**Test Data:**
- Email: 'test123@gmail.com'
- Password: 'Test12345!'
- Confirm Password: 'Test12345!'

**Steps:**
1. Ввести валидный email в поле Email
2. Ввести валидный пароль в поле Password
3. Ввести тот же пароль в поле Confirm Password
4. Нажать на кнопку регистрации

**Expected Result:**
- Регистрация выполнена успешно
