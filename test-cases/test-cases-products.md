# Test Cases Products

## TC-PROD-001 - Получение списка товаров авторизованным пользователем

**Description:** Проверка получения списка товаров авторизованным пользователем

**Preconditions:**
- Пользователь зарегистрирован
- Пользователь авторизован
- Получен действующий access token

**Test Data:**
- Access Token: действующий токен авторизованного пользователя

**Steps:**
1. Отправить GET-запрос на получение списка товаров
2. Передать в запросе действующий access token в заголовке Authorization

**Expected Result:**
- Сервер возвращает HTTP 200 OK
- В ответе возвращается список товаров
- Каждый товар содержит поля: id, title, price, stock



## TC-PROD-002 - Получение списка товаров без авторизации

## TC-PROD-003 - Проверка обязательных полей товара

**Description:** Проверка наличия обязательных полей в объектах списка товаров

**Preconditions:**
- Пользователь зарегистрирован
- Пользователь авторизован
- Получен действующий access token

**Test Data:**
- Access Token: действующий токен авторизованного пользователя

**Steps:**
1. Отправить GET-запрос на получение списка товаров
2. Передать в запросе действующий access token в заголовке Authorization
3. Проверить ответ сервера
4. Проверить каждый объект товара в полученном списке
5. Проверить наличие полей id, title, price, stock
6. Проверить, что значения указанных полей не являются null

**Expected Result:**
- Сервер возвращает HTTP 200 OK
- В ответе возвращается список товаров
- Каждый товар содержит поля: id, title, price, stock
- Значения обязательных полей не являются null
