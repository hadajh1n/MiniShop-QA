# Requirements

## 1. Регистрация

- Пользователь может зарегистрироваться по email и паролю
- Email обязателен
- Email должен иметь корректный формат
- Пароль должен содержать от 8 до 20 символов
- Пароль должен содержать минимум одну цифру
- Пароль должен содержать минимум одну заглавную букву
- Пароль и подтверждение пароля должны совпадать
- Нельзя зарегистрировать уже существующий email

## 2. Авторизация

- Пользователь может войти с помощью email и пароля
- При успешной авторизации сервер возвращает access token
- Запросы, требующие авторизации, должны содержать access token
- При неверных данных пользователь получает сообщение об ошибке

## 3. Товары

- Авторизованный пользователь может получить список товаров
- Каждый товар содержит: id, title, price, quantity
- Цена товара не может быть отрицательной
- Количество товара не может быть меньше 0

## 4. Заказы

- Авторизованный пользователь может создать заказ
- Заказ содержит: id, userId, productId, quantity, status
- quantity должна быть от 1 до 99
- Неавторизованный пользователь не может создать заказ
- При успешном создании сервер возвращает HTTP 201 Created
- Новый заказ получает статус CREATED

## 5. Статусы заказа

- Жизненный цикл заказа: CREATED → PAID → SHIPPED → DELIVERED
- Отмена разрешена: CREATED → CANCELLED; PAID → CANCELLED
- Отмена заказа со статусом SHIPPED или DELIVERED невозможна
